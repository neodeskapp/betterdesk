# Contributing to BetterDesk

Changes come in as pull requests against `main`. The guide for contributors
is on the website:

- [Contributing](https://betterde.sk/docs/development/contributing): how to
  propose a change, what a pull request needs, commit messages and
  contributor licensing.
- [Building from source](https://betterde.sk/docs/development/building) and
  [Tests and checks](https://betterde.sk/docs/development/tests-and-checks):
  how to build the server with its web console and which checks to run
  before you open the pull request.
- [Architecture](https://betterde.sk/docs/development/architecture): how the
  repository is laid out and how the parts fit together.
- [Translations](https://betterde.sk/docs/development/translations): how to
  improve or add a language of the console.

Report security problems privately, as [SECURITY.md](SECURITY.md) describes,
not in a public issue.

BetterDesk is under [AGPL-3.0](LICENSE). Who keeps the copyright in a
contribution, and how outside work is credited, is in
[Contributor licensing](https://betterde.sk/docs/development/contributing#contributor-licensing).
